# Install Prerequisites

This guide covers what you need to run Oasis Spa locally and deploy on Render.

## Required

- Node.js (LTS)
- npm
- Neon PostgreSQL project (for `DATABASE_URL`)

## Optional (Local Docker)

- Docker Desktop (to run `docker-compose up --build`)

## Next Steps

- Create `server/.env` (see `ENV_SETUP.md`)
- Run the app locally:

```bash
docker-compose up --build
```
